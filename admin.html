অ্যাডমিন প্যানেল সেটআপ

নিরাপদ অ্যাডমিন লগইন, পণ্য যোগ/সম্পাদনা, অর্ডার দেখা এবং বিক্রির রিপোর্ট চালু করতে Supabase ব্যাকএন্ড সংযোগ প্রয়োজন। এই পেজটি এখন সেটআপ নির্দেশনা দেখাচ্ছে—এটি এখনো লগইন বা অর্ডার ব্যবস্থাপনা করছে না।

পরবর্তী সেটআপ

  1. Supabase-এ একটি প্রজেক্ট তৈরি করা
  2. ডেটাবেস স্কিমা চালানো
  3. নিরাপদ Auth এবং Admin user সেট করা
  4. Netlify-তে environment variables যোগ করা

নিরাপত্তার জন্য অ্যাডমিন পাসওয়ার্ড কোডে রাখা হবে না।
